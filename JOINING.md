# Welcome to the server

Hey guys, welcome to the new server!

## First time joining

1. Open Eaglercraft and connect to the server using the server address.
2. Wait for the proxy to ask you to register.
3. Type this in chat:

```text
/register YOUR_ACCOUNT_NAME YOUR_PASSWORD
```

Example:

```text
/register shafi MySecretPassword123
```

## Very important

Your **account name and password keep your player data safe**. Your items, XP, location, and other data are connected to your account's saved identity.

Remember both your account name and password. Do not use a friend's account, and do not share your password.

Your Eaglercraft name can be different from your account name. For example:

```text
Eaglercraft name: shafi_the_bomber
Account name:     shafi
```

## Joining again later

Type this in chat:

```text
/login YOUR_ACCOUNT_NAME YOUR_PASSWORD
```

Example:

```text
/login shafi MySecretPassword123
```

## Rules for account names

- Use 3 to 20 letters, numbers, or underscores.
- Use a name you will remember.
- Do not register someone else's old Eaglercraft name.
- Passwords must be at least 8 characters long.

If you forget your password, contact the server owner. Do not create another account, because it will not automatically contain your old items.
